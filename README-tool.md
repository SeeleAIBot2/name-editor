# 名字有别 · 剧好卖嵌入版 v2

把命名管理前移到策划阶段，在生成后检查卡片，再对成稿进行逐处复检。完全本地运行，无外网、CDN、模型调用或正文上传。

## 打开和集成

- **先体验**：双击 `preview.html`，这是可操作的静态宿主预览。`name-editor.html` 是同一工具的独立页面。
- **接入宿主**：将合并版 `index.vue` 放回用户原始 Nuxt 页面的位置。在原后台顶部点击「名字合规」进入，点击「返回剧本管理」返回。工具关闭后通过 `v-show` 保留本次内存；刷新清空。
- `index.vue` 保留原后台业务，工具独立在 `neSrcdoc` 中。iframe 只开放 `allow-scripts allow-downloads allow-modals`，不开放同源访问，不能读取后台会话。
- 当前目录没有完整 Nuxt 项目与宿主依赖；已验证静态预览与脚本，**未运行宿主 Nuxt build**。接入后需由完整项目验证类型、路由和既有后台流程。

## 三个工作台

### 01 策划 / 角色命名台

预置两部虚构作品、三个角色。可手动添加作品与作品 ID，新增角色时生成稳定 `character_id`。角色记录包含作品、男主/女主/配角/反派、正式名、允许别名、禁用称呼、命名状态和版本。

- 原有 **25 项硬违禁名**不可删除，正式名与别名命中不能保存或锁定，候选标记「违禁」。连续子串匹配，不扩展谐音。
- 全局正式名 / 别名完全重复标记「已占用」并阻止保存；Unicode 码点编辑距离 1 或同姓标记「风险」，允许人工判断后保存。
- 批量候选框展示「可用 / 风险 / 违禁 / 已占用」和已占用角色 ID；点「填入角色」再人工确认保存。本版批量评估、逐角色提交，不会一键批量锁名。
- 锁定角色不能直接修改；在表中点击「解锁」，变为待确认，版本递增。编辑后重新锁定，角色 ID 不变。
- 角色库 JSON 整库导入 / 导出。导入先完整校验，失败时保持当前库；不能绕过锁定修改或删除角色，已有角色版本不能倒退。

**存储**：角色库、卡片和稿件仅当前页面内存有效。sandbox 不开放 localStorage；没有服务端持久化。离开前导出角色库 JSON，下次导入恢复。当前卡片文本、检查证据和成稿不在角色库 JSON 内。

### 02 卡片门禁

选择作品，填写卡片名和文本；自动展示本作品字典 Prompt，包含角色 ID、正式名、别名、禁用称呼、状态、版本和 25 项硬规则。复制失败时会选中文字，可用 Cmd/Ctrl+C。

选择单角色范围可检查其他角色姓名 / 别名串入；全作品范围允许本作品角色共同出现。

- **阻断**：违禁名、禁用称呼、正式名冲突，或单角色范围串名。
- **待确认**：未登记称呼、其他作品的已登记角色。候选不自动归属；点「去登记」只填表，人工确认保存后重新检查。
- **通过**：有文本且本次规则检查没有问题。修改文本、字典或范围后结果失效。

证据提供原文片段、行号、UTF-16 起止位置；点击定位选择原文。位置从 1 展示，核心索引从 0，end 排他。手工补充的候选未出现在正文时，核心位置为 -1、行号 0。

未知称呼采用【称呼】标记、行首说话人标签和有限中文姓氏启发式检测；可手工补充待核对称呼。存在漏报与误报，通过仅代表本次规则范围，不替代阅读复核，也不对任意自然语言做人物消歧。Prompt 是本地文本，不会自动发送给模型。

### 03 全文复检

保留原有多稿 TXT 导入 / 粘贴、角色与别名映射、跨稿撞名和一字近似、单篇频率、候选生成、逐处改名预览和导出前全文违禁复检。

全文后处理是独立流程，角色映射需与角色库人工核对，不自动同步或自动替换全文。修改默认不勾选，导出生成 UTF-8 TXT 副本，不覆盖原文件，不把人名自动改成他 / 她。全文页的用户追加违禁名单仅该页工具使用；命名台与卡片门禁使用不可删的25项核心名单。
