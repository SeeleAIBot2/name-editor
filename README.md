# 名字有别｜故事创作平台角色命名与文本复检工具

静态离线页面，打开后在浏览器本地处理文本，不上传用户输入。

## 功能

- 策划/角色命名台
- 角色 ID、正式名、别名和禁用称呼管理
- 项目侧违禁姓名硬拦截
- 卡片门禁与角色字典 Prompt
- 多稿撞名、近似名和频率复检
- 改名预览及导出前检查

## 隐私边界

当前页面只使用浏览器内存处理用户输入，不调用后端 API、统计 SDK 或外部模型。刷新或关闭页面后，未导出的内容会丢失。角色库可通过页面的 JSON 导入/导出功能备份。

## 说明

这是纯静态工具页面，不包含宿主管理后台、项目售卖、上传接口或业务管理模块。
